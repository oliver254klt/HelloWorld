# HelloWorld

Autor: Oliver Brown

Primera aplicación con Expo y TypeScript usando componentes, props y estado (useState).

## Requisitos
- Node.js y pnpm
- App Expo Go en el celular (misma red Wi-Fi que la computadora)

## Ejecutar el proyecto
```bash
pnpm install
pnpm start
```
Escanea el código QR con Expo Go.

## Cómo se creó
```bash
pnpm create expo-app HelloWorld --template blank-typescript
```
